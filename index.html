Entrainement de La Casa

📱 Cette application fonctionne de deux façons : installée (recommandé) ou en version Web.
✅ Recommandé : installer l’application
(meilleure lisibilité + moins de bugs)
  • Samsung Internet
    Appuie sur ☰ (les 3 traits) ➜ Installer en tant qu’application Web
  • Chrome / Firefox / Edge
    Appuie sur ⋮ (3 points) ➜ Installer l’application
  • iPhone (Safari)
    Bouton Partager 📤 ➜ Ajouter à l’écran d’accueil
Ensuite, ouvre l’app depuis l’icône ajoutée sur l’écran d’accueil.
🌐 Sans installation
Utilise la version Web directement :
👉 Ouvrir le site Web d’entraînement
⚠️ En mode Web, l’affichage peut varier selon le navigateur.
