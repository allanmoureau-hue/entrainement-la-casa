Entrainement de La Casa
Conseillé : installe l’app pour éviter le logo orange et avoir un affichage plus stable.
🌐 Ouvrir en version Web Sans installation
Comment installer ? ▾
Samsung Internet
Menu ☰ (3 traits) → Installer en tant qu’application Web
Chrome / Firefox / Edge
Menu ⋮ (3 points) → Installer l’application / Ajouter à l’écran d’accueil
iPhone (Safari)
Bouton Partager → Sur l’écran d’accueil
Astuce : pour l’icône correcte, installe depuis github.io (pas script.google.com).
